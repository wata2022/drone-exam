# 二等無人航空機操縦士 学科試験対策アプリ

このアプリケーションは、二等無人航空機操縦士の学科試験対策のための問題集を提供します。
問題は「無人航空機の飛行の安全に関する教則（第４版）」に基づいて作成されています。

## セットアップ方法

1. 必要なパッケージをインストール:
```bash
pip install -r requirements.txt
```

2. アプリケーションの実行:
```bash
streamlit run app.py
```

## 機能

- ランダムに出題される三肢択一式の問題
- 即座に採点と解説の確認が可能
- 問題のシャッフル機能

## 注意事項

このアプリケーションは学習支援ツールです。実際の試験対策には、公式の教材や資料も併せてご活用ください。
